Bazel Community Round-up for August 2022

By Jingwen Chen on 08 September 2022

Welcome to the August issue of the Bazel Community Round-up, where we collect and share content about Bazel over the month.

Announcements

  • Call for Proposals for BazelCon 2022 (Nov 16-17, New York City) is now open. Submit your proposal here.
    • BazelCon home page
    • bazel-discuss thread
  • Slack is now kindly sponsoring slack.bazel.build, thanks to Erik Kerber.
  • The frontend for bzlmod packages, registry.bazel.build, has a new UI thanks to Max Goisser.
  • Bazel is an official project in the new Google’s Open Source Software Vulnerability Rewards Program.
  • Radhika, PM for Bazel, is running a user study for Android App Development with Bazel. Please fill up this form if you develop Android apps.
    • bazel-discuss thread
  • Bazel 6.0 LTS is now being prepared for release.
    • Release tracker issue
    • bazel-discuss thread
  • Bazel 5.3rc2 is available for testing.
